Tips

  • • Use standard notation: R, L, U, D, F, B, M, E, S
  • • Use lowercase for wide moves: r, l, u, d, f, b
  • • Add ' for counterclockwise (e.g., R' or r')
  • • Add 2 for double moves (e.g., R2 or r2)
  • • Optional: Use [ ] or ( ) to group moves
